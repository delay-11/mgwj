# 먹고왔지

다녀온 맛집과 카페를 기록하고 관리하는 개인용 웹 앱입니다.

## 소개 (v1.1)

- 다녀온 장소를 사진, 지역, 영업시간, 부가서비스 등과 함께 기록해요
- 종류(맛집/카페), 지역, 시군구, 지금 영업중 여부로 필터링해서 볼 수 있어요
- 라이트/다크 테마를 지원해요

## 업데이트 내역

### v1.1

- 메모를 적으면 목록 카드 썸네일 아래에 미리보기로 표시돼요
- 사파리 주소창 때문에 시트(설정/상세보기 등)의 핸들바·닫기 버튼이 안 보이던 문제를 고쳤어요
- 핸들바를 눌러도 반응하지 않던 문제를 고쳤어요
- 새로운 장소를 등록할 때 좌우로 스와이프해서 단계를 넘길 수 있어요
- 데이터를 불러오는 동안 로딩 표시가 나타나요
- 개인정보처리방침 페이지를 추가했어요
