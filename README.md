# 먹고왔지

다녀온 맛집과 카페를 기록하고 관리하는 개인용 웹 앱입니다.

## 버전

1.0.0

## 소개

- 다녀온 장소를 사진, 지역, 영업시간, 부가서비스 등과 함께 기록해요
- 종류(맛집/카페), 지역, 시군구, 지금 영업중 여부로 필터링해서 볼 수 있어요
- 라이트/다크 테마를 지원해요

## 기술 스택

- HTML / CSS / JavaScript (프레임워크나 빌드 도구 없이 순수 웹 표준으로 작성)
- 브라우저 `localStorage`를 이용한 데이터 저장

## 파일 구조

```
index.html   화면 마크업
style.css    스타일
app.js       앱 로직
```
